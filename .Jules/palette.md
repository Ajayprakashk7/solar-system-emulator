## 2024-08-23 - Focus States for Accessibility
**Learning:** Found that multiple interactive elements like buttons lack keyboard focus indicators, which hurts accessibility.
**Action:** Always add focus-visible styles like `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-400 focus-visible:ring-offset-2 focus-visible:ring-offset-black` to interactive elements to improve keyboard navigation accessibility.
