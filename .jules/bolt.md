## 2024-05-18 - GPU Acceleration for Asteroid Belt

**Learning:** When dealing with dynamic instanced groups in React Three Fiber (like thousands of tumbling asteroids), continuously updating individual instance matrices via `setMatrixAt` inside `useFrame` creates unnecessary CPU load and garbage collection pressure, even if batched. Moving the rotation logic to the GPU via vertex shaders using `onBeforeCompile` on standard materials is significantly faster and eliminates per-frame array mutations. It is crucial to remember to also rotate vertex normals (by overriding `#include <beginnormal_vertex>`) to ensure lighting still works properly with the new geometry positions.
**Action:** When animating many small instanced objects (like debris, leaves, particles) where the motion is deterministic, offload the transformation to the vertex shader by passing initial states and velocities via `instancedBufferAttribute` and a global time uniform, avoiding O(N) CPU updates entirely.
