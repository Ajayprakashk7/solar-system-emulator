## 2025-02-27 - Inline array allocations in useFrame
**Learning:** In React Three Fiber `useFrame` callbacks (like those updating 9 planets simultaneously), passing inline arrays `[x, 0, z]` to context update functions causes high-frequency garbage collection (540 objects per second), leading to micro-stutters. Interestingly, isolated V8 microbenchmarks may deceptively show array allocation as *faster* than mutation due to inline caching or dead code elimination, but in complex React apps, the GC pauses are the real bottleneck.
**Action:** When updating coordinates in `useFrame`, always pass primitive scalar arguments `(x, y, z)` and mutate a stable, long-lived `useRef` array or `Vector3` object under the hood. Never allocate objects inline inside continuous render loops.
