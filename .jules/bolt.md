## 2024-05-24 - Fix Frustum Culling and React Hover Bottlenecks
**Learning:** React state (`useState`) should not be used for simple `onMouseEnter`/`onMouseLeave` hover effects in UI components overlaid on an intensive WebGL canvas, as it causes unnecessary main-thread re-renders that compete with the render loop. Tailwind CSS `hover:` variants are much more efficient. Also, when enabling `frustumCulled={true}` for dynamically positioned `InstancedMesh` or `Points` objects in R3F, a fixed `boundingSphere` must be explicitly constructed and assigned (e.g., `meshRef.current.boundingSphere = new Sphere(new Vector3(0, 0, 0), radius)`), otherwise they will be incorrectly culled based on a zero-radius uninitialized matrix.
**Action:** Always prefer native CSS pseudo-classes for simple UI interactions over React state. For performance optimization in Three.js/R3F, explicitly calculate and assign bounding spheres to custom or procedurally generated geometries and instanced meshes before enabling frustum culling to ensure accurate culling logic.
