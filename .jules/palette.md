## 2024-05-24 - Add focus visible styles for keyboard navigation in UI components
**Learning:** Found that almost none of the interactive UI buttons in `components/solar-system/ui/` have explicit keyboard focus styles (e.g., `focus-visible:ring-2`, `focus-visible:outline-none`). In this particular repo, there's a global CSS setting a 4px border-radius on `focus-visible` that breaks circular elements (like `ExitButton` and `ControlMenu`), so applying explicit tailwind focus utility classes including `focus-visible:rounded-full` (e.g. `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-400 focus-visible:rounded-full`) is needed to maintain circular shapes and provide accessible focus indication.
**Action:** Add explicit `focus-visible` styles to circular interactive UI components (`SpeedControl`, `ControlMenu`, `ExitButton`, etc.) to provide visible keyboard accessibility without being overridden by the global style.
