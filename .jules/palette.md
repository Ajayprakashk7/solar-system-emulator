## 2024-10-04 - High-contrast focus states in dark mode 3D contexts
**Learning:** Custom styled interactive UI overlay components in dark-mode 3D contexts often lack native focus indicators, significantly hindering keyboard navigation for users.
**Action:** Always add explicit, high-contrast Tailwind focus-visible utility classes (e.g., focus-visible:ring-2 focus-visible:outline-none) to these elements to ensure clear focus states for keyboard users.
