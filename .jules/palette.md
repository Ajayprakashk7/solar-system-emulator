## 2024-05-18 - Fix Keyboard Navigation Accessibility For Custom Circular Elements

**Learning:** Global CSS in `app/globals.css` applies a 4px `border-radius` directly to `*:focus-visible`. This global rule breaks the focus outline display for rounded interactive elements, particularly those using `rounded-full` or custom Framer Motion components acting as buttons (`<motion.div role="button">` or `<motion.button>`). When relying strictly on the global `.css` rule, these circular buttons are rendered with rectangular/squared-off keyboard focus outlines instead of properly matching their intended rounded shapes, creating a visually jarring experience.
**Action:** Always apply explicit Tailwind focus utility classes (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[color]`) directly on custom interactive circular elements (like UI controls in this project) to override the conflicting global `border-radius: 4px` on `focus-visible`. This guarantees that the focus ring follows the element's actual shape and provides an accessible, pleasant keyboard navigation experience.
