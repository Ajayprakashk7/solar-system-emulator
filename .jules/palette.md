## 2025-01-20 - Mobile UI Control Overlap and Custom Focus States
**Learning:** Floating auxiliary controls (like SpeedControl) positioned at top-4 right-4 on mobile overlap with contextual menus (like ControlMenu and ExitButton). Additionally, custom circular interactive elements (<motion.div role="button">) suffer from broken focus outlines due to global CSS setting a 4px border-radius on focus-visible.
**Action:** Position auxiliary controls near the bottom on mobile (e.g., bottom-24 right-4) while resetting the opposite property on larger breakpoints (sm:bottom-auto sm:top-6). Always apply explicit Tailwind focus-visible utility classes (focus-visible:outline-none focus-visible:ring-2) to custom interactive elements to ensure proper focus state styling that respects element shapes.
